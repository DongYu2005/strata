# strata · 分层记忆

用生成的文字世界测记忆。世界只有一条宗旨：**宏观变得慢，微观变得快。** 好的记忆不是记住一切，而是知道每条记忆能信多久、过期了退回哪一层。长上下文、RAG、笔记、写进参数……都可以放进来比。

- **世界**：固定三层，地区 → 村 → 人。每个人有几样特质（卖什么、守不守信），要么自己有，要么随村、随地区。人隔 10~50 天变一次，村 50~250 天，地区 250~1250 天。参数只有 4 个：size、tau、ratio、mu。
- **玩法（采办）**：你替东家跑货，每天在昨天落脚的村子醒来，接一单「找一个卖铁、守信的人」。本村卖什么看得见，别村只能凭记忆；同一地区里串村当天就到，去别的地区走 1 天。守不守信要真做成一单才知道。一世到头会死，世间照常流转，重生时记得前世的一切。
- **几种采办**：随便找（不记）、只信最新、只信多数、分层推断（参照上限）、全知（天花板）。去哪、找谁的规则都一样，只差在怎么用记忆。

```bash
uv sync
uv run strata                  # 自己玩一局：上下键选去哪、找谁，回车定下，q 退出
uv run stratabench             # 跑分：几种采办在同样的世界里比成单率
uv run python -m unittest discover -s tests
```

默认世界（3 个地区 × 3 个村 × 4 人，三种货）20 个种子的成单率：

| | 第 1 世 | 第 4 世 | 重生头 20 天 |
|---|---|---|---|
| 随便找 | 40% | 32% | 35% |
| 只信最新 | 60% | 28% | 35% |
| 只信多数 | 56% | 37% | 32% |
| 分层推断 | 68% | 60% | 57% |
| 全知 | 87% | 81% | 81% |

「只信最新」一世不如一世：它对很久以前的记录也照单全收。
